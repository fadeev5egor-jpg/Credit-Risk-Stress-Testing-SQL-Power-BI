# Corporate Credit Portfolio Stress Testing (SQL + Power BI | Basel III / IFRS 9)

End-to-end аналитический проект по оценке кредитных рисков корпоративного портфеля и макроэкономическому стресс-тестированию на выборке из *300 000 записей*.

![Dashboard Preview](dashboard_preview.png)

## Бизнес-задача
Оценить устойчивость корпоративного кредитного портфеля к макроэкономическим шокам (изменение ВВП, процентных ставок, безработицы и кредитных спредов) в соответствии с концепцией ожидаемых кредитных убытков (*Expected Credit Loss — ECL) по стандартам **Basel III / IFRS 9*.

## Стек технологий
* *PostgreSQL (SQL):* проектирование аналитической витрины risk_portfolio.v_portfolio_stress_test, агрегация рисковых параметров, расчёт PD/LGD/EAD и сценарного моделирования.
* *Power Query (M):* очистка данных, нормализация региональных разделителей и приведение типов данных.
* *DAX & Power BI Desktop:* создание динамических мер (Total EAD, Base EL, Stressed EL, EL Uplift %) и интерактивного дашборда для анализа чувствительности по сценариям, отраслям и кредитным рейтингам.

## Ключевые метрики и формулы
* *Total EAD* (SUM([ead])) — совокупный объём кредитных требований под риском дефолта.
* *Base EL* (SUMX(..., [ead] * [lgd] * [base_pd])) — базовые ожидаемые потери до применения макрошоков.
* *Stressed EL* (SUMX(..., [ead] * [lgd] * [stressed_pd])) — ожидаемые потери в условиях стресс-сценариев (baseline, mild, adverse, severe, gfc_like, covid_like).
* *EL Uplift %* (DIVIDE([Stressed EL] - [Base EL], [Base EL], 0)) — относительный прирост ожидаемых убытков.
